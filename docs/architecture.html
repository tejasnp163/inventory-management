Request Data Flow

1
User changes a filter
useFilters.js composable holds four reactive refs: selectedPeriod, selectedLocation, selectedCategory, selectedStatus. Shared across all views via import.
2
View watches filter refs and re-fetches
Each view's watch() or onMounted() calls the matching method in api.js, passing the current filter state as a plain object.
3
api.js builds the HTTP request
Methods use URLSearchParams to append only non-'all' filters. Axios sends GET http://localhost:8001/api/<endpoint>?warehouse=X&category=Y…
4
FastAPI filters in memory
apply_filters() runs list comprehensions over the in-memory data for warehouse, category, and status. filter_by_month() handles both YYYY-MM strings and quarter aliases (Q1-2025 → ['2025-01','2025-02','2025-03']).
5
Pydantic validates and serialises
Response model (e.g. List[InventoryItem]) strips extra fields and coerces types before the JSON response is sent.
6
Vue stores raw data in refs, derives metrics via computed
Raw arrays land in ref() variables (e.g. allOrders). KPIs, chart data, and totals are computed() properties so they update automatically without re-fetching.

API Endpoints

Path Description Filter Params
GET /api/inventory All inventory items warehouse, category
GET /api/inventory/{id} Single inventory item —
GET /api/orders All orders warehouse, category, status, month
GET /api/orders/{id} Single order —
GET /api/dashboard/summary KPI metrics (inventory value, low stock, pending orders) warehouse, category, status, month
GET /api/demand Demand forecasts with trend —
GET /api/backlog Backlog items + purchase order flag —

GET /api/reports/monthly-trends Month-over-month order trends —
